# Iconos de tecnologías

Los símbolos de Java, Spring, C#, Python, Kotlin, JavaScript, TypeScript, HTML5, CSS3, Angular, Unity, Jetpack Compose, Git y Maven proceden de [Devicon](https://github.com/devicons/devicon), revisión `7330accdbc47e2dc0c19789a48533c4a3c50fe58`.

Se han integrado en tarjetas SVG locales. El símbolo de Unity se adaptó a tonos claros para mantener el contraste sobre el fondo oscuro. La licencia MIT original se conserva en [licenses/devicon-MIT.txt](licenses/devicon-MIT.txt). Los nombres y marcas pertenecen a sus respectivos titulares; su uso identifica tecnologías, no implica afiliación.

El resto de gráficos, monogramas y animaciones se diseñó para este perfil. Las tarjetas VHDL son ilustraciones, no capturas de una implementación en funcionamiento.
